# 📊 Streamlit Marketing Campaign Analytics App

## 📌 Business Overview
An interactive web dashboard built with Streamlit and Plotly to enable marketing teams to monitor spend efficiency, track Cost Per Acquisition (CPA), and measure Return on Ad Spend (ROAS) across paid and organic channels.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Data Wrangling:** Pandas
- **Visualization:** Plotly Express
- **Deployment:** Streamlit Community Cloud

## 🚀 Features
- **Dynamic KPI Monitoring:** Live metrics updating based on user selection.
- **Multiselect Filters:** Slice performance data by marketing channel.
- **Interactive Visualizations:** Scatter plots and comparative bar graphs.
- **Data Export:** Built-in CSV downloader for reporting.
